# MasterTop 1.0.7 Release Notes

Status: draft until App Store and Google Play submission.

## Store Text

Что нового:
- Вкладка "Каталог" переименована в "Лента".
- В карточке мастера фото теперь можно открыть крупно.
- Улучшены контакты мастера: номер стал заметнее, звонок открывается через иконку телефона.
- Добавлена карта с точкой мастера и выделенная кнопка построения маршрута.
- В настройках появилась поддержка для предложений и жалоб.
- Удаление аккаунта перенесено в управление аккаунтом и защищено SMS-подтверждением.
- Внизу настроек теперь показывается версия установленной сборки.

## Short Store Text

Обновили карточку мастера: крупный просмотр фото, заметные контакты, звонок через иконку телефона, карта с точкой и маршрутом. Добавили поддержку, SMS-подтверждение удаления аккаунта и отображение версии в настройках.

## Implemented Changes

- Catalog tab renamed to Feed.
- Master photos can be opened in a larger fullscreen view from the master card.
- Master contact block is more prominent, and phone calls start from a phone icon button.
- Location block now shows the master point on a map and highlights the route action.
- Client and master settings now include support for suggestions and complaints.
- Support tickets are visible and manageable in the admin panel.
- Account deletion moved deeper into account management and requires SMS confirmation.
- App settings now show the installed app version and build number.

# MasterTop 1.0.8 Release Notes

Status: draft until App Store and Google Play submission.

## Store Text

Что нового:
- Исправлена проблема, из-за которой после обновления приложения некоторых пользователей выбрасывало из аккаунта.
- Старые сохраненные сессии теперь автоматически переводятся на новый формат авторизации.
- Улучшена стабильность входа при запуске приложения после обновления из Google Play и App Store.

## Short Store Text

Исправили проблему, из-за которой после обновления приложения некоторых пользователей выбрасывало из аккаунта. Сессии теперь сохраняются и автоматически обновляются на новый формат авторизации.

## Implemented Changes

- Preserved legacy mobile sessions that were saved before refresh tokens were added.
- Added backend session upgrade flow for legacy access-token-only sessions.
- Delayed startup API calls until legacy sessions are upgraded, preventing accidental logout during app launch.

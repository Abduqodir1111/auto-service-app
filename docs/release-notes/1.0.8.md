# MasterTop 1.0.8 Release Notes

Status: draft until App Store and Google Play submission.

## Store Text

Что нового:
- Исправлена проблема, из-за которой после обновления приложения некоторых пользователей выбрасывало из аккаунта.
- Старые сохраненные сессии теперь автоматически переводятся на новый формат авторизации.
- Улучшена стабильность входа при запуске приложения после обновления из Google Play и App Store.
- Улучшена форма добавления объявления для мастеров: телефон подставляется автоматически, черновик сохраняется при выходе, город и адрес можно определить по GPS.
- Добавлен удобный выбор графика работы и загрузка фото прямо с камеры или из галереи.

## Short Store Text

Исправили сохранение входа после обновления и улучшили добавление объявлений: GPS-адрес, черновики, график работы и фото с камеры или галереи.

## Implemented Changes

- Preserved legacy mobile sessions that were saved before refresh tokens were added.
- Added backend session upgrade flow for legacy access-token-only sessions.
- Delayed startup API calls until legacy sessions are upgraded, preventing accidental logout during app launch.
- Defaulted the workshop phone field to the registered master phone while keeping it editable.
- Removed the unused Telegram/username field from the workshop editor.
- Persisted workshop form drafts across app restarts.
- Added GPS address/city detection next to the address fields and reverse geocoding after map point selection.
- Replaced the free-form opening hours input with presets and manual from/to time selection.
- Added camera capture as a photo source and allowed Android camera permission for release builds.
